# Blue Letter Bible Suite — Privacy Policy

**Effective version:** 5.2.51.49

Blue Letter Bible Suite is an independent, unofficial Chrome extension that provides Bible-study tools around supported Bible websites, including Blue Letter Bible (BLB), Bible-reference handling, Show on BLB, Double-Click BLB, study sessions, and KJV case-sensitive search.

## Information processed by the extension

The extension may process:

- Bible references, selected text, words, phrases, and search queries that the user explicitly interacts with.
- Study-session titles, notes, references, dates, and related preferences entered or generated by the user.
- Website/page text needed to identify Bible references, Strong's values, or Bible words for features the user enables. This page-text processing occurs locally for the enabled feature; the extension does not send page text to its developer.
- Extension settings such as enabled sites, feature settings, study-session preferences, and search history.

The extension does not collect or request passwords, authentication credentials, financial information, health information, precise location, contacts, or personal communications.

## Clipboard and downloads

Clipboard writes occur only when a user invokes a copy feature.

Study-session PDF files are generated from extension data and saved through the browser's download facility when the user requests an export.

## Local storage

Study sessions, notes, search history, preferences, and related extension state are stored using Chrome's local extension storage.

The extension does not operate a separate analytics or advertising database.

## External websites and sharing

The extension does not send user data to the developer or to advertising, analytics, or data-broker services.

When the user requests a search or opens a Bible destination, the extension may navigate the browser to the requested third-party website, including Blue Letter Bible and other supported Bible websites. A query, selected reference, or reference list included in such a navigation is therefore received by that destination website under that website's own privacy policy.

The extension's `b cs` case-sensitive KJV matching uses the bundled verified original-case KJV corpus locally. Matching itself is performed inside the extension.

When the extension creates or updates clipboard content for its copy-as-link feature, that clipboard write is initiated by the user's requested copy action. When resulting references are opened in BLB MultiVerse, those references are included in the destination URL sent to BLB.

## Chrome Web Store Limited Use

Blue Letter Bible Suite uses information received through Chrome extension APIs only to provide and improve its disclosed Bible-study features and related operational functionality.

The extension does not sell user data, use user data for personalized advertising, or transfer user data to advertising platforms, data brokers, or other information resellers. The developer does not permit humans to read user data except where required by applicable law or necessary for security or abuse prevention.

The use of information received through Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## No sale of personal information

The extension does not sell personal information. It does not include advertising or third-party analytics code.

Blue Letter Bible Suite is not affiliated with, endorsed by, or sponsored by Blue Letter Bible.

## Changes

If the extension's data practices materially change, this policy will be updated before the corresponding Chrome Web Store release.
