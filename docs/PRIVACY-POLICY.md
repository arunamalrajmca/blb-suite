# Blue Letter Bible Suite — Privacy Policy

This policy applies to the current published version of the extension.

Blue Letter Bible Suite is an independent, unofficial Chrome extension that provides Bible-study tools around supported Bible websites, including Blue Letter Bible (BLB), reference handling, Show on BLB, Double-Click BLB, study sessions, and KJV case-sensitive search.

## Information processed by the extension

The extension may process:

- Bible references, selected text, words, phrases, and search queries that the user explicitly interacts with.
- Study-session titles, notes, references, dates, and related preferences entered or generated by the user.
- Website/page text needed to identify Bible references, Strong's values, or Bible words for features the user enables. This page-text processing occurs locally for the enabled feature; the extension does not send page text to its developer.
- Extension settings such as enabled sites and study-session preferences.

## Clipboard and downloads\n\nClipboard writes occur only when a user invokes a copy feature. Study-session PDF downloads are generated from extension data and saved through the browser's download facility.\n\n## Local storage

Study sessions, notes, search history, preferences, and related extension state are stored using Chrome's local extension storage. The extension does not operate a separate analytics or advertising database.

## External websites

When the user requests a search or opens a Bible destination, the extension may navigate the browser to the requested third-party website, including Blue Letter Bible. A query or reference included in such a navigation is therefore received by that website under that website's own privacy policy.

The extension's `b cs` case-sensitive KJV matching uses the bundled verified original-case KJV corpus locally. When the extension creates or updates clipboard content for its copy-as-link feature, that clipboard write is initiated by the user's requested copy action. Matching itself is performed inside the extension. When the resulting references are opened in BLB MultiVerse, those references are included in the destination URL sent to BLB.

## No sale of personal information

The extension does not sell personal information. It does not include advertising or third-party analytics code. It is not affiliated with, endorsed by, or sponsored by Blue Letter Bible.

## Changes

If the extension's data practices materially change, this policy should be updated before the corresponding Chrome Web Store release.
