1. Get Started

Blue Letter Bible Suite adds quick ways to send Bible references, words, phrases, and selected passages to Blue Letter Bible (BLB).

Open the Suite controls

Click the Blue Letter Bible Suite extension icon. The popup contains the main switches and study controls.

Settings are remembered for the websites where you use them.

First use

After installing the extension, open the Suite popup and choose the features you want to use. Site-specific features can request access when you enable them.

Good to know: Bible-related websites can have useful features enabled automatically. On ordinary websites, you can turn the features on when you need them.

2. Search from the Address Bar

The quickest way to send a search to BLB is the browser's address bar.

  1. Focus the address bar.
  2. Type b, then a space.
  3. Enter a Bible reference, word, phrase, Strong's number, or search with a range.
  4. Press Enter.
TypeExampleWhat opens
Bible referenceb Romans 8:28Romans 8:28 in BLB
Book and chapterb Psalm 150Psalm 150
Strong'sb G3056The Strong's entry
Phraseb "body of Christ"A BLB phrase search
Rangeb faith NTA search limited to the New Testament
You can use common Bible abbreviations such as Rom 8:28, Ps 150:1-6, and 1 Cor 13:4-7.

3. Select Text and Open It in BLB

On supported pages, select text and use Show on BLB. The Suite examines the entire selection, so a long paragraph or several paragraphs can be used.

Important: You do not need to select only the reference. If a larger selection contains Bible references, the Suite looks through the whole selection and opens the references it can identify.

What happens to your selection?

Your selection containsResult
One resolvable Bible referenceThat reference opens in a normal BLB verse view.
Two or more resolvable Bible referencesAll of the references open together in one MultiVerse view.
No resolvable Bible referenceThe Suite can use the selection as a search when appropriate; it does not treat random or incomplete text as a Bible reference.

Example: selecting a whole passage

Scripture tells us to “exercise thyself unto godliness” (1 Timothy 4:7). This isn't a passive suggestion—it’s an active command. Godliness requires work, effort, and intentionality.

The Apostle Paul instructs us to “work out your own salvation with fear and trembling” (Philippians 2:12).

The two references in this selection are 1 Timothy 4:7 and Philippians 2:12. The expected result is one MultiVerse view containing both references.

When references are found in a selection, the Suite opens those references directly. You will not get an extra Criteria Search window for the same selection.
When a selection has no explicit Bible reference, the Suite scans the whole selection for KJV wording. It prefers a meaningful phrase that identifies one verse, records that verse, then moves past the matched KJV region before continuing. This reduces repeated or noisy search fragments while still allowing later distinct verses to be found.

4. Multiple References and MultiVerse

MultiVerse is used when a selection contains more than one Bible reference.

  1. Select text containing the references.
  2. Choose Show on BLB by floating button, right-click, or Alt + B.
  3. The Suite collects the references it finds.
  4. BLB opens them together in MultiVerse.
SelectionExpected result
Romans 8:28One normal reference view.
Romans 8:28; Philippians 2:12One MultiVerse view with both references.
A whole article or paragraph containing several referencesReferences found throughout the selection are collected together.
Repeated references are not opened as separate copies just because they appear more than once in the selected text.

5. Show on BLB

Show on BLB is available in three convenient ways:

Floating button

When enabled for the current website, a small Show on BLB button appears near the bottom-right of the page. Select text, then click it.

Right-click menu

Select text, right-click, and choose Show on BLB.

Keyboard shortcut

Select text and press Alt + B.

Site setting

The Show on BLB setting controls the floating button and the right-click menu. It is remembered separately for websites.

The Alt + B shortcut is available independently of the floating button and right-click menu.

6. Double-Click BLB

Turn on Double-Click BLB in the Suite popup for a fast way to open Bible-related text.

Double-clickTypical result
A KJV wordOpen that word in BLB.
A Strong's number such as G3056 or H430Open the Strong's entry.
A Bible book or supported abbreviationOpen the corresponding Bible book.
A part of a nearby Bible referenceUse the surrounding reference to open the correct verse.

Examples include selecting or double-clicking 150 in Psalm 150, or 28 in Romans 8:28.

The same nearby-reference understanding is used by Double-Click BLB, Show on BLB, right-click Show on BLB, and Alt + B.

7. Bible References in Web Pages and PDFs

On supported web pages and PDF documents, you can select Bible references and send them to BLB.

  1. Select the reference or a larger passage containing references.
  2. Right-click and choose Show on BLB, or use Alt + B.
  3. One reference opens normally; multiple references open in MultiVerse.
PDF tip: If the PDF text is selectable, the Suite can work with the selected text just like a web page.

8. Webster's 1828

On supported Webster's 1828 dictionary pages, the Suite can find Bible references and provide a convenient BLB button.

  • Use the Show on BLB button provided on the page.
  • If the page contains one Bible reference, that reference opens normally.
  • If the page contains multiple Bible references, they can open together in MultiVerse.
  • The dictionary word itself is not treated as a Bible reference.

9. Bible-Link Redirection

When Redirect External Bible Links is enabled, supported Bible links from other websites can open through BLB instead of sending you to the original destination.

  1. Open the Suite popup.
  2. Turn on Redirect External Bible Links.
  3. Click a supported Bible reference link on a web page.
This setting is separate from Show on BLB and Double-Click BLB.

10. Study Sessions and History

Study Sessions help you collect Bible references, Strong's entries, search terms, and notes under a topic while you study.

Start a study

  1. Open the Suite popup.
  2. Choose or create a study topic.
  3. Start recording.
  4. Study normally. The Suite records supported study activity for that topic.
  5. Add your own notes in the Notes area.
  6. Stop the session when you are finished.

History

The History controls let you review the study information by category:

  • Verse References — open the references collected for the topic.
  • Strong's — open the Strong's entries collected for the topic.
  • Search Terms — search the terms collected during the study.

Download your study

Use Download PDF to save study notes. You can download:

  • Selected Topic — the current topic.
  • All Topics — all stored topics together.
  • By Date — studies within a selected date range.
Reminder: Study Sessions are optional. You can use the Bible-search features without recording a study.

11. Copy Bible Text with Links

BLB's copy controls can preserve clickable Bible links when rich text is copied from supported BLB pages.

  • Use BLB's normal Copy or Copy to Clipboard button.
  • This also applies to supported MultiVerse views.
  • When you want plain text only, use Ctrl + Shift + V in apps that support plain-text paste.

13. Case-Sensitive KJV Search

The case-sensitive KJV routing is available from the browser address bar with the cs command.

CommandWhat it does
b cs JesusUses native BLB search for the ordinary Jesus query.
b cs JESUSUses the local verified KJV corpus when the exact all-caps form matters.
b cs LORDFinds the exact KJV capitalization LORD and sends the matching references to BLB MultiVerse.
b cs "Lord God"Finds the exact case-sensitive phrase.
Corpus: the local engine searches the verified original-case KJV corpus containing all 31,102 verses. Capitalization is significant for both individual words and phrases.
Destination: matching local exact-case references are sent directly to Blue Letter Bible's native MultiVerse in the current tab. The case-sensitive search engine is internal implementation; b cs opens the resulting BLB destination directly.
Normal search is unchanged: b ... continues to use the existing normal BLB Suite search behavior. Only b cs ... enters the new case-sensitive routing layer.

15. Troubleshooting

Show on BLB is not visible

  • Open the Suite popup and make sure Show on BLB is ON for that website.
  • Remember that the floating button and right-click menu are controlled by this setting.
  • You can still try Alt + B.

A selected reference opened incorrectly

  • Select a little more surrounding text so the complete Bible reference is included.
  • For a larger passage, you can select the whole passage; the Suite checks the entire selection for references.
  • Check that the book name and chapter/verse are written clearly.

Several references are not opening together

  • Make sure the references are part of the same selection.
  • Use Show on BLB or Alt + B after selecting the passage.
  • If references are found, the Suite opens them in MultiVerse rather than a separate Criteria Search window.

Double-click is not doing anything

  • Open the Suite popup and turn on Double-Click BLB.
  • Try it on ordinary page text rather than links, buttons, form fields, or editable text.

Study information is not being recorded

  • Check that the correct study topic is selected and recording is started.
  • Open History after you have performed a supported study action.
In short: Search with b, select text and use Show on BLB, double-click when you want a quick lookup, and use Study Sessions when you want to keep a record of your study.
